base model
Five YOLO variants (11n/s/m, 12n/s) run in your browser via ONNX Runtime (WASM); COCO-SSD runs via TensorFlow.js. The bigger models (11m especially) see more but download slower. Everything runs locally, so your image never leaves your device. It’s only added to the shared dataset when you save it. All were trained on COCO (80 everyday classes), so none has a word for “building.” that blind spot is the point.
what the machine sees
the detector only recognizes what its dataset taught it. everything it has no word for dissolves into noise. slide the confidence bar to adjust the threshold of blurry computer vision.
